# Black Box — La caja negra

> Reto 2 · Frontier Lab10

Portal de documentación técnica para la solución del reto **"La caja negra"**.

## Objetivo

Comprender el comportamiento de un servicio heredado sin código ni documentación, y construir un reemplazo que responda exactamente igual — errores incluidos.

## Documentación

Abre **`index.html`** en un navegador para acceder al portal completo de documentación.

### Estructura

- `docs/system-design.md` — Visión general del sistema y principios de diseño
- `docs/architecture.md` — Diagramas de arquitectura y componentes
- `docs/specification.md` — Plantilla de especificación del comportamiento observado
- `docs/reverse-engineering-strategy.md` — Estrategia de ingeniería inversa por fases
- `docs/testing-strategy.md` — Categorías de pruebas y políticas de comparación
- `docs/deployment.md` — Instrucciones provisionales de despliegue
- `experiments/experiment-log.md` — Plantilla de registro de experimentos

## Entregables del reto

- [ ] Reemplazo implementado y desplegado
- [ ] Especificación del comportamiento (`docs/specification.md`)
- [ ] Registro de experimentos (`experimentos.jsonl`)
- [ ] Pruebas de equivalencia (`tests/`)

> **Advertencia:** los formatos definitivos deben verificarse contra el README oficial del reto antes de la entrega.
